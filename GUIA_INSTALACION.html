📲 1. ¿Cómo instalo ARMONÍA en mi teléfono?

Una PWA necesita estar en una URL https:// pública para poder instalarse. El archivo HTML solo, abierto con doble click, no funciona como app — tiene que estar "alojado" en algún lugar de internet. Hay tres maneras de lograrlo, de más fácil a más profesional:

⚡ MÁS RÁPIDO

Netlify Drop

Arrastra la carpeta, obtienes URL en 30 segundos. Sin crear cuenta obligatoria. Perfecto para probar.

⭐ RECOMENDADO

GitHub Pages

Gratis de por vida, versionado, backup automático. Base para cualquier proyecto serio.

🔧 DESARROLLO

Servidor local

Solo para probar en tu Mac/PC. No se puede instalar desde otro teléfono.

🅰️ Ruta A — Netlify Drop (2 minutos, sin GitHub)

1
Localiza la carpeta del proyecto. Está donde Gemini guardó los archivos: APP ARMONIA. Contiene como mínimo APP_ARMONIA_Prototipo.html, manifest.webmanifest, sw.js, icon-192.svg, icon-512.svg.
2
Renombra APP_ARMONIA_Prototipo.html a index.html (para que Netlify lo detecte como página principal). Alternativa: dejar como está y acceder con tuurl.netlify.app/APP_ARMONIA_Prototipo.html.
3
Ve a app.netlify.com/drop — es la página oficial de arrastrar-y-soltar.
app.netlify.com/drop
📁

or browse to upload
4
Arrastra la carpeta completa (no los archivos sueltos) al recuadro. En segundos verás una URL tipo https://harmonious-cat-123abc.netlify.app.
5
Abre esa URL en tu teléfono. Desde ahí sigues los pasos de "Instalar en iPhone/Android" más abajo.
✅ Ventajas: sin cuenta obligatoria, en 2 minutos, HTTPS gratis, siempre disponible.
⚠️ Limitación: si no creas cuenta y cierras la sesión, no podrás actualizarla después — tendrías que volver a arrastrar. Por eso al cuarto o quinto cambio conviene pasar a la Ruta B.

🅱️ Ruta B — GitHub Pages (10 minutos, recomendada)

1
Crea cuenta en github.com. Es gratis. Usa tu email campoltro@gmail.com.
2
Crea un repositorio nuevo. Clic en el + arriba a la derecha → New repository. Nómbralo armonia (o lo que quieras). Marca Public. No marques "Add README". Clic en Create repository.
3
Sube los archivos. En la página del repo recién creado, haz clic en uploading an existing file (link chiquito) o usa el botón Add file → Upload files.
4
Arrastra toda la carpeta APP ARMONIA (con todos los archivos). Escribe un mensaje de commit corto ("primera versión"). Clic en Commit changes.
5
Activa GitHub Pages. En el repo, ve a Settings (arriba a la derecha) → en el menú lateral Pages → en Source elige Deploy from a branch y selecciona la rama main (carpeta / (root)). Clic en Save.
6
Espera 1-2 minutos. Tu URL será https://tu-usuario.github.io/armonia/APP_ARMONIA_Prototipo.html (o si renombraste a index.html, solo /armonia/). GitHub te la mostrará arriba en Settings → Pages.
✅ Ventajas: hosting permanente gratis, cada cambio que subas se publica automáticamente, historial de versiones, URL profesional, base para todo lo demás.

🆎 Ruta C — Servidor local (solo para probar en tu Mac/PC)

Ya tienes el archivo servir.command en la carpeta. Doble click en él y abrirá Terminal mostrando http://localhost:8765/APP_ARMONIA_Prototipo.html. Úsalo solo para desarrollo — no puedes instalar en un teléfono externo desde aquí.

⚠️ Limitación: el teléfono tendría que estar en la misma Wi-Fi que tu Mac y acceder por IP local — frágil y no recomendado para uso real.

🐙 2. ¿Tener GitHub ayuda? Sí, en TODO

Para un proyecto que quieres publicar en App Store y Play Store algún día, GitHub no es opcional — es como tener email. Te explico qué te da:

QuéPor qué te importa
Hosting gratis de por vidaGitHub Pages te da una URL pública tu-usuario.github.io/armonia que nunca se cae mientras GitHub exista. Sustituye Netlify.
Backup automáticoCada cambio queda guardado. Si borras algo por accidente o el disco de tu Mac se muere, tu trabajo está a salvo.
Historial de cambiosVer qué cambió entre semana y semana, volver a una versión anterior si algo se rompe. Imposible de vivir sin esto una vez lo pruebas.
ColaboradoresCuando contrates pedagogos, diseñadores, programadores, cada uno puede contribuir sin pisar el trabajo del otro.

Open source opcionalSi en V2 decides hacer parte del curriculum comunitario, GitHub es donde eso vive.

🤖 3. ¿Cómo se hace el Tutor IA real?

Estado actual del prototipo: el tutor responde con mensajes guionados muy convincentes. Son buenos para demostrar la visión, pero no entiende preguntas nuevas. Para que entienda cualquier pregunta con profundidad de conservatorio, hay que conectarlo a un modelo de lenguaje real.

¿Por qué pasar por un Worker intermedio? Porque si la app llama directo a Gemini, cualquiera que abra el código en el navegador ve tu clave de API y te gasta el presupuesto. El Worker guarda la clave como secreto, valida quién puede usarla, y rate-limita por usuario.

Paso 1 — Obtener clave de Gemini

  1. Crea cuenta en console.anthropic.com con tu email campoltro@gmail.com
  2. Verifica el teléfono (requerido)
  3. Ve a Settings → API Keys → Create Key. Dale nombre "armonia-prod"
  4. Copia la clave (empieza por sk-ant-...). Guárdala en un lugar seguro — no aparecerá otra vez
  5. En Plans & Billing carga 5 USD de crédito inicial para pruebas

Paso 2 — Desplegar el Cloudflare Worker

El Worker es una función serverless. Cloudflare te da 100,000 peticiones gratis diarias. Más que suficiente para miles de usuarios antes de pagar un centavo.

  1. Crea cuenta en cloudflare.com (gratis)
  2. En el dashboard, ve a Workers & Pages → Create Application → Create Worker
  3. Nómbralo armonia-tutor y despliega el worker de ejemplo
  4. Clic en Edit code
  5. Pega el código de abajo (también está en el archivo cloudflare-worker.js de la carpeta)
  6. Clic en Save and Deploy
  7. Ve a Settings → Variables → Environment Variables → Add variable. Nombre: ANTHROPIC_API_KEY, valor: tu clave sk-ant-.... Marca "Encrypt". Guarda
  8. Tu Worker ahora está en https://armonia-tutor.tu-usuario.workers.dev. Copia esa URL

Código del Worker (copia y pega):

// armonia-tutor.js — Cloudflare Worker
export default {
  async fetch(request, env) {
    // CORS para que la app en GitHub Pages pueda llamar
    const CORS = {
      "Access-Control-Allow-Origin": "*",
      "Access-Control-Allow-Methods": "POST, OPTIONS",
      "Access-Control-Allow-Headers": "Content-Type"
    };
    if (request.method === "OPTIONS") return new Response(null, { headers: CORS });
    if (request.method !== "POST") return new Response("Method not allowed", { status: 405 });

    const { messages, context } = await request.json();

    // SYSTEM PROMPT — aquí vive la "personalidad pedagógica"
    const system = `Eres el tutor de ARMONÍA, una app profesional de armonía musical.
Hablas el idioma del usuario (es/en/pt/fr/it).
Eres riguroso como un profesor de Berklee o conservatorio, pero cálido y directo.
Explicas con ejemplos concretos de canciones reales en el estilo del usuario: ${context?.style || 'jazz'}.
Si preguntan algo que NO sabes o es ambiguo, preguntas por contexto en lugar de inventar.
Formato: usa HTML simple (b, i, br) para énfasis. Sé conciso: 150-250 palabras por respuesta.
Cuando propones un acorde o progresión, inclúyelo en formato que la app pueda reproducir:
[PLAY:Cm7,F7,Bbmaj7] — la app convierte esto en un botón clicable.
Contexto actual del usuario:
- Lección: ${context?.lesson || 'Libre'}
- Partitura abierta: ${context?.score || 'Ninguna'}
- Nivel: ${context?.level || 'Intermedio'}`;

    const r = await fetch("https://api.anthropic.com/v1/messages", {
      method: "POST",
      headers: {
        "x-api-key": env.ANTHROPIC_API_KEY,
        "anthropic-version": "2023-06-01",
        "content-type": "application/json"
      },
      body: JSON.stringify({
        model: "claude-sonnet-4-6",
        max_tokens: 1024,
        system,
        messages
      })
    });
    const data = await r.json();
    return new Response(JSON.stringify(data), { headers: { ...CORS, "Content-Type": "application/json" } });
  }
};

Paso 3 — Integrar el Worker en la app

En el HTML de la app, busca la función tutorReply(text) y reemplázala por esta versión que llama a tu Worker:

const WORKER_URL = "https://armonia-tutor.tu-usuario.workers.dev";

async function tutorReplyAI(text) {
  const chat = activeChat();
  const history = chat.messages.slice(-10).map(m => ({
    role: m.who === 'user' ? 'user' : 'assistant',
    content: m.text.replace(/<[^>]+>/g, '')  // strip HTML for AI
  }));
  history.push({ role: 'user', content: text });

  try {
    const r = await fetch(WORKER_URL, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        messages: history,
        context: {
          lesson: 'Dominantes secundarios',
          score: 'All the Things You Are',
          style: document.getElementById('styleSelect').value,
          level: 'Intermedio'
        }
      })
    });
    const data = await r.json();
    return data.content?.[0]?.text || 'Lo siento, hubo un problema. Intenta otra vez.';
  } catch (e) {
    return 'Error de red. Revisa tu conexión e intenta de nuevo.';
  }
}

Y en tutorSend() cambia la línea appendToChat(tutorReply(t),'ai') por tutorReplyAI(t).then(reply => appendToChat(reply,'ai')).

🎉 Listo. Ahora cada pregunta se envía a Gemini con el contexto de la lección, estilo y últimos 10 mensajes. Gemini responde como un verdadero profesor de Berklee. Las respuestas se guardan en el chat y sobreviven entre sesiones.

En la práctica: una conversación típica de 5 intercambios cuesta ~$0.015 (1.5 centavos). Con $5 de crédito tienes ~330 conversaciones para probar. Cuando tengas usuarios de pago, la regla es: tier Pro de $14.99/mes cubre ~500-800 conversaciones de tutor, muy por encima del uso real del promedio.

⚠️ Protección contra abuso: antes de publicar ampliamente, añade al Worker: (1) rate limit por IP (50 req/día gratis, más si es usuario Pro), (2) validación de token de sesión, (3) lista blanca de dominios (Access-Control-Allow-Origin específico).

Alternativas al Worker

  • Vercel Edge Functions — similar a Cloudflare, buena integración con Next.js si en el futuro migras.
  • Supabase Edge Functions — si ya usarás Supabase para base de datos y autenticación.
  • AWS Lambda — potente pero con más fricción inicial.
  • OpenAI GPT-5 en vez de Gemini — mismo patrón, cambia la URL y el formato. Gemini suele dar mejores explicaciones pedagógicas largas.
